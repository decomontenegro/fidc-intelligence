# FIDC Intelligence 🏦

**Cérebro do Mercado de Crédito Estruturado — Brasil**

Dashboard interativo com todos os FIDCs do Brasil, dados públicos da CVM.

## Acesso
👉 [decomontenegro.github.io/fidc-intelligence](https://decomontenegro.github.io/fidc-intelligence)

## Dados
- Fonte: CVM Dados Abertos
- Posição: Fevereiro/2026
- 5.507 FIDCs mapeados | R$ 831 bilhões em PL
- Gestoras, administradoras, segmentos, inadimplência

## Features
- **Visão Geral** — Bubble chart D3.js por PL e segmento
- **Fundos** — Tabela completa com busca e filtros (virtual scroll)
- **Gestoras** — Ranking por PL e quantidade
- **Administradoras** — Ranking por PL e quantidade  
- **Mercado** — Treemap por segmento + análise de inadimplência
